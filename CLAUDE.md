# Instruções do projeto

Antes de planejar, implementar ou corrigir qualquer tarefa neste repositório,
leia e siga integralmente a política compartilhada em `AGENTS.md`.

`AGENTS.md` é a fonte canônica para separação de papéis, cobertura automatizada,
handoff para QA, tratamento de testes com falha e gate de conclusão.
